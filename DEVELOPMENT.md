# Development Tooling

This project uses the following tools and extensions to maintain code quality,
consistent formatting, accessibility, and a productive development workflow.

## VS Code Extensions

### ESLint

Provides real-time ESLint feedback in VS Code. It reports code quality,
TypeScript, React, and accessibility issues directly in the editor.

### Prettier - Code formatter

Formats the code according to the project's Prettier configuration,
ensuring consistent formatting across the project.

### Stylelint

Provides Stylelint feedback for CSS and SCSS. It helps enforce the project's
styling conventions and catches invalid or problematic CSS/SCSS.

### SCSS IntelliSense

Provides autocomplete and language support for SCSS, including variables,
mixins, functions, and other SCSS features.

## Browser Extensions

### axe DevTools

Used to manually test the application for accessibility issues in the browser.
It complements the automated accessibility checks provided during development.

## Project Tooling

### ESLint

Lints JavaScript and TypeScript code and enforces the project's coding
standards and rules.

### Prettier

Automatically formats source files according to the project's formatting rules.

### Stylelint

Lints CSS and SCSS files and enforces consistent and valid styling.

### @axe-core/react

Runs automated accessibility checks during development and reports accessibility
violations in the browser console.
